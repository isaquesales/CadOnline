Um site que promove a substituição do uso de papel com publico alvo de uso em instituições de ensino.

É descentralizado, funcionando localmente na instituição sem internet, com a possibilidade de sincronzar online tornando acessível em qualquer lugar, a partir de quando for sincronizado.

Elementos da interface:
Topbar com rotas principais de acesso
Sidebar com todas as outras rotas
Main Content com Shell lateral 

Rotas:
Administração Global
Administração Institucional
Sala de Aula
Grupos
Pessoal
