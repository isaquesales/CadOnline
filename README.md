# CadOnline
- CadOnline é um site que promove a substituição do uso de papel com publico alvo de uso em instituições de ensino.

- É descentralizado, funcionando localmente na instituição sem internet, com a possibilidade de sincronzar online tornando acessível em qualquer lugar, a partir de quando for sincronizado.

# Elementos da Interface
- Topbar com botões e informações de acesso rápido
- Sidebar com todas as outras categorias
- Main Content com Shell centralizado

# Especificações Técnicas

Implementação com ASP.NET no padrão MVC (dotnet core 10), Entity Framework (SQLite 3) e NLua para Scripting e analise de dados.
