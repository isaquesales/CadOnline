sistema com login com apenas nome de usuário + senha?

# login

ao apertar login aparece um prompt com a lista de:
    - usuários salvos no cookie do navegador, formatado em:
        - Meu Nome da Silva / Escola123
    - opção de adicionar, na qual:
        - pede nome
        - pede senha
    - abaixo, opção de criar conta.

ao apertar em criar conta:

prompt que ao criar um usuário pede:
Nome de usuário
Nome
Escola (id aleatorio. instituição pode definir se requer autorização dela para entrar)
Turma (Dá a lista a partir do id da instituição selecioanda)
Curso (Opcional se definido pela escola uma lista. Dá a lista a partir do id da instituição selecioanda)
Turno (Matutino/ Vespertino/ Noturno)

# logout
ao apertar logout sai do contexto do usuário
